# tmdl-for-agents

Reference catalogue of TMDL object types and properties, exported from the TOM assembly, for use by agents.

- The goal and scope of this repo are defined in `FICHA.md` (pending: it will be added with maintainer approval).
- `exports/` holds the generated catalogue; do not edit it by hand, regenerate it.
- Commits use conventional commits, in English. Code changes go through a pull request.
