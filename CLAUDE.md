# Agent instructions

This repository is **public and in pre-release**. Write every issue and commit with that in mind:
no client names, no real engagements, no credentials, and nothing from private repositories or
local machines.

It is maintained under the maintainer's own rules: its north is [FICHA.md](FICHA.md), and the
`experto` agent (`.claude/agents/experto.md`) reviews and merges each pull request against it.

## Rules specific to this repo

- **Never add a name — an object type or a property — to anything an agent reads unless it is in
  the catalogue** (`exports/tmdl-tom.catalog.json`). This library exists to stop invention, so it
  cannot contain any. If a name is missing, the fix is to re-extract the catalogue from a newer TOM
  assembly, not to hand-write the name.
- **The catalogue is regenerated by reflection over TOM, never edited by hand.** It is the source
  of truth; record the assembly version and date in its header when it is regenerated.
- **Every number in the README is counted from the catalogue**, not typed. Until a check backs a
  number, do not write it.
- **TOM names vs TMDL keywords.** The catalogue holds PascalCase TOM names (`FormatString`); TMDL
  writes them lowercase-first (`formatString`). Reference cards give both. The catalogue is the
  authority on which names exist.
- **CI runs on GitHub runners, never on a self-hosted one.** The repo is public, and a self-hosted
  runner would execute fork pull requests on the maintainer's machine.
- Public-facing docs (README, CONTRIBUTING, reference cards) are in English.

## Checks before a pull request

```bash
python scripts/check_repo.py
python -m unittest discover -s tests
```

Both must pass; the required `Validate` check on `main` runs the same commands.
